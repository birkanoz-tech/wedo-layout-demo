# Customer Projects Folder / Müşteri Projeleri Klasörü

Bu klasör içine eklediğiniz tüm `.xml` uzantılı yerleşim projelerine canlı URL parametresi ile doğrudan erişilebilir.

## Örnek Kullanım:
Eğer `projects/` klasörüne `firma-a.xml` adında bir dosya eklerseniz:

Müşterinize vereceğiniz canlı adres:
👉 `https://birkanoz-tech.github.io/wedo-layout-demo/?project=firma-a`

Uygulama açılırken otomatik olarak `projects/firma-a.xml` dosyasını çekecek ve 3D sahnede canlı gösterecektir.
